# Sistema POS - Preguntas Frecuentes

tags: general, sistema, pos

## Productos
El sistema permite gestionar productos con nombre, precio de venta, precio de compra, stock, código SKU y categoría.
Los productos se pueden crear, modificar, eliminar y consultar.
Cada producto tiene un código SKU único.
El stock se actualiza automáticamente al realizar ventas o compras.

## Ventas
Las ventas registran productos vendidos, cantidades, precios, descuentos aplicados y el total.
Se puede aplicar descuentos por producto o globales a la venta.
El sistema calcula automáticamente el subtotal, descuentos y total.
Las ventas se pueden consultar por fecha, rango de fechas o por producto.
No se pueden modificar ventas ya registradas, solo anularlas.

## Clientes
Los clientes tienen nombre, documento de identidad (DNI/RUC), teléfono, email y dirección.
Se pueden registrar nuevos clientes y modificar datos existentes.
Los clientes pueden tener múltiples compras registradas.

## Reportes
El sistema genera reportes de ventas por período, producto, cliente y vendedor.
Los reportes incluyen totales, cantidades, promedios y gráficos.
Se puede exportar a PDF y Excel.

## Usuarios
El sistema tiene roles: ADMIN, VENDEDOR, ALMACENERO.
ADMIN puede crear/modificar usuarios, ver todos los reportes.
VENDEDOR puede registrar clientes y realizar ventas.
ALMACENERO puede gestionar productos e inventario.

## Inventario
El stock se actualiza automáticamente con cada venta y compra.
Se pueden realizar ajustes de inventario manuales.
El sistema alerta cuando el stock de un producto es bajo.
